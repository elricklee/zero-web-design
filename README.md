# 珞珈拾光

武汉大学校园主题的单屏合成小游戏原型。主界面在一个屏幕内展示分数与技能、合成场地、下一枚记忆与融合图鉴；排行榜、融合图鉴详情、游戏说明和四片拼图手札由按钮打开为独立小页。页面不依赖预设 UI 库或外部游戏素材。

## 运行

直接用 Chrome 打开 `index.html` 即可游玩，无需安装依赖或启动构建服务。

## 页面与玩法

- 点击或触摸游戏场地投放元素；同级元素碰撞后自动合成。
- 合成获取积分与珞珈共鸣能量；能量充满后可使用“共鸣清场”。
- 单局限时两分钟，暂停、重新开始、溢出结算均可使用。
- 游戏结束后将最高成绩加入本地演示排行榜；分数与进度保存在当前浏览器的 `localStorage` 中。
- 累计积分可解锁三页珞珈手札的记忆碎片；每页四片，拼合成一幅校园风景。
- 音效可由顶部控制按钮开关；键盘支持空格投放、方向键微调落点与 Q 键清场。

排行榜包含前端演示成绩，不代表线上比赛排行；正式部署需接入服务端存储与校验。
