# zero-web-design

# 珞珈拾光

武汉大学四季校园主题的单屏合成小游戏。主界面同时展示分数与技能、合成场地、下一枚记忆和融合图鉴；排行榜、技能选择、图鉴详情、游戏说明和四片拼图手札由按钮打开为独立小页。页面不依赖预设 UI 库。

## 运行

需要 Node.js 18 或更新版本。运行 `node server.js` 后访问 `http://127.0.0.1:4173`。不要直接使用 `file://` 打开：服务器会提供共享排行榜 API。

## 页面与玩法

- 点击顶部春、夏、秋、冬切换全页配色、游戏元素、融合图鉴与手札。各季的累计积分、最佳成绩及碎片独立保存。
- 点击或触摸场地投放元素；同级元素碰撞后自动合成。
- 合成获取积分与共鸣能量；从技能选择页选择技能，能量充足后可使用“春风拂落”“樱雨回旋”或“珞珈晨曦”。
- 单局限时两分钟，暂停、重新开始、溢出结算均可使用。
- 游戏结束后输入昵称提交成绩。排行榜由 Node 服务统一保存于 `data/leaderboard.json`，所有访问同一服务的玩家共享榜单。
- 每个季节累计积分独立解锁四块照片碎片，拼合该季武大校园照片。
- 音效可由顶部控制按钮开关；键盘支持空格投放、方向键微调落点与 Q 键释放技能。

## 四季校园照片

将已获授权使用的武汉大学实景照片放入 `assets/seasons/`，并按以下文件名保存：

- `spring.jpg`
- `summer.jpg`
- `autumn.jpg`
- `winter.jpg`

手札照片和当季图鉴会读取对应照片。缺少照片时界面会显示“等待添加实景照片”，不会用插画冒充实景照。

## 排行榜部署说明

`server.js` 使用 Node.js 内置模块，不需要安装 npm 依赖。成绩经过服务端分数、单局时长、一次性游戏会话和提交频率校验；同季同昵称只保留最佳成绩。排行榜仍是无账号的展示榜，昵称可能被他人冒用，前端分数也不能抵御有意伪造。若用于正式赛事，应加入登录/校园身份认证、服务端权威游戏模拟或更严格的反作弊，并使用具备备份的数据库。

默认监听 `127.0.0.1:4173`。部署到服务器时设置 `HOST=0.0.0.0` 和 `PORT`，并确保 `data/` 目录可持久写入；多实例部署需替换 JSON 文件存储为共享数据库。
